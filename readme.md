# TripMe ✈️

Site de viagens para descobrir destinos incríveis, compartilhar experiências e conectar viajantes.

## Páginas

- **MinhaViagem** – Diário de bordo, roteiros personalizados e galeria de memórias
- **NosEncontre** – Comunidade global, encontros presenciais e grupos de viagem
- **Conselhos** – Dicas de planejamento, segurança e economia

## Tecnologias

- HTML5
- CSS3
- JavaScript (vanilla)
- Google Fonts (Playfair Display + Inter)

## Como usar

Basta abrir o arquivo `index.html` no navegador. Nenhuma dependência ou build necessário.

## Estrutura

```
tripme/
├── index.html
└── style.css
```
